# Hospital Management Dashboard

## Overview
The **Hospital Management Dashboard** is a data visualization tool designed to streamline hospital operations by tracking patient admissions, diagnoses, doctor feedback, and billing details. This dashboard provides valuable insights to improve hospital workflow and patient care.

## Dataset
<a href="https://github.com/harsh-118/Hospital-Management-Dashboard-/blob/main/Papollo-Healtcare-Dataset.xlsx">Dataset</a>

## Features
- **Patient Admission & Discharge Tracking:** View patient admit, discharge, and follow-up dates.
- **Bed Occupancy Analysis:** Understand the distribution of patients in private, general, and ICU beds.
- **Doctor Feedback Volume:** Monitor patient feedback data for various doctors.
- **Diagnosis Insights:** Analyze common diagnosis types and their frequencies.
- **Billing & Insurance Analysis:** Compare billing amounts with health insurance coverage.

## Data Insights
- **Patient Flow Management:** Helps in managing hospital occupancy effectively.
- **Financial Tracking:** Monitors billing and insurance trends to ensure transparency.
- **Doctor Performance Evaluation:** Tracks patient feedback to improve healthcare quality.
- **Disease Trend Analysis:** Identifies common diagnoses to enhance preparedness and response.
- **Dashboard:** <a href="">Dashboard</a>

## How to Use
1. Select the **Patient ID** or a date range to filter relevant data.
2. Analyze **bed occupancy, doctor feedback, and diagnosis trends** using interactive visualizations.
3. Compare **billing amounts** with health insurance to track financial insights.
4. Use the insights for hospital workflow improvement and decision-making.
